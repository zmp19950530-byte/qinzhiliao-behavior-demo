02 / 决策依据

从市场信号到版本决策

以下信息用于支持本轮升级优先级：亲子记录承担高频留存，AI亲子督导承担高价值服务，导师与课程承接承担后续转化。

1. 亲子记录是高频刚需

管理层结论：成长记录是头部产品长期经营的核心入口，适合作为亲智聊1.0升级的高频基础能力。

行业盘 母婴亲子行业月活稳定在3500万+，2024年2月人均单月启动80.5次。说明育儿工具不是低频内容消费，而是日常打开场景。
头部表现 亲宝宝单日人均启动3.8次、14天活跃留存51.1%、中重度用户占比62%、用户独占率53.5%。说明成长记录能形成长期粘性和独立使用价值。
功能信号 亲宝宝、妈妈网孕育、宝宝树孕育都把相册时间轴、成长记录、亲友共享作为核心能力。亲智聊第一版必须有轻量时间轴和家庭成员上传分享。

2. AI督导是高价值刚需

管理层结论：家庭指导需求已从知识学习进入场景化指导阶段，AI督导可成为更低门槛的即时服务入口。

指导盘 中国儿童中心调研显示，66.5%的家长参加过家庭教育指导讲座；参加者在学业、升学、职业选择方面的焦虑比例分别低9.9、8.7、9.0个百分点。
冲突场 CNNIC报告显示未成年网民1.93亿、互联网普及率97.2%，经常看短视频比例从2018年的40.5%升至2022年的54.1%。手机和短视频已经成为亲子沟通高压场景。
AI接受 家长糖AI宣称基于20万家庭咨询经验，提供成长日记解读和亲子对话分析；小猿AI官方表达“降低亲子冲突”。亲智聊不做题库，而是做冲突后的关系复盘。

3. 打通后才有商业必要性

管理层结论：记录提供真实输入，督导提供即时价值，导师/课程承接高价值问题，三者具备打通必要。

新需求 家长糖AI以“上传对话录音/截图，分析孩子情绪与需求”为卖点，并宣称20万+家庭咨询经验。说明用户已接受把真实沟通交给AI分析。
服务承接 孩子王官方描述显示近7000名育儿顾问、500+门店、180+城市、数十万场亲子活动。家庭教育和亲子服务存在从线上到线下的承接空间。
版本建议 亲智聊应把“记录 -> 三张卡 -> AI对话 -> 小任务 -> 周/月总结 -> 导师/课程”设计成闭环，而不是把亲子记录和AI对话分散成两个入口。
汇报结论：亲智聊不宜进入重型相册或泛AI问答竞争，而应围绕真实亲子记录建立AI亲子教练系统。第一版只要跑通轻上传、时间轴、三张卡、深度对话和一个可执行任务，就具备测试留存与转化的最小闭环。
03 / 需求判断

两个功能，各自独立，又必须打通

单独做亲子记录，容易变成相册；单独做AI督导，容易变成泛问答。亲智聊的产品价值在于把真实记录变成教练输入，再把AI建议变成亲子关系行动。

亲子记录是高频入口

它承接家长“看见孩子、保存孩子、分享孩子、回看孩子”的天然动机。低龄是照片视频，小学后是作业冲突、聊天记录和家长感受。

高频留存 / 家庭协作 / 情感资产

AI督导是高价值服务

家长最大的痛点不是不知道理论，而是具体场景里不知道怎么做。AI督导要提供理解、解释、话术和小任务。

专业信任 / 具体话术 / 服务转化

打通后形成产品飞轮

越记录，AI越懂孩子和家庭；越懂，督导越具体；越具体，家长越愿意尝试；新的尝试又会产生新的记录。

记录 -> 督导 -> 行动 -> 再记录

06 / 用户路径

从一条记录，到一次真正的督导

第一版链路必须短，像发朋友圈一样上传，像抽卡一样获得洞察，像和教练聊天一样深入，最后落到一个可执行任务。

01

进入亲子记录

看到孩子成长时间轴，家庭成员共同上传与互动。

02

上传素材

图片、音视频、对话文本、微信聊天提取都可作为记录材料。

03

添加标签

选择日常、闪光、崩溃瞬间，以及事件标签和可见范围。

04

生成AI卡片

系统按场景弹出三张卡，可能出现温度卡、游戏卡或奖励卡。

05

查看卡片内容

获得解读、镜子、话术、任务等具体输出。

06

和督导师聊聊

进入AI亲子督导对话页，继续追问并形成下一步行动。

07 / 版本建议

第一版要轻，但必须有新感觉

重点不是堆功能，而是让用户第一次感到：我记录的不只是孩子的照片，AI真的从这一刻里看见了孩子，也看见了我。

第一版必须做

  • 亲子记录首页：时间轴、图/音视频/文字显示、情感标签、AI督导入口、上传入口。
  • 上传记录页：选择素材、微信聊天提取、文字感受、情感标签、事件标签、谁可以看。
  • AI督导触发：选择单条或多条记录，弹出三张卡片，主卡在上，两张副卡在下。
  • AI督导对话页：上传资料、文字/语音输入、三个滑动卡片、推荐话题一行展示。
  • 隐藏卡：温度卡、游戏卡、奖励卡按需随机出现，强化惊喜感。

第一版不做重

  • 不做重型云盘和复杂相册管理，避免与亲宝宝正面竞争存储能力。
  • 不做完整心理测评体系，测评卡可作为隐藏福利，不放主链路。
  • 不做大课程学习体系，先测试“记录 -> 卡片 -> 对话”的闭环。
  • 不做泛社区内容，避免稀释亲子记录和AI督导主线。
  • 不做医学或心理诊断，只做日常陪伴、家庭教育指导和关系复盘。
