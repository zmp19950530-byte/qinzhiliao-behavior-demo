# 亲智聊 - 市场需求分析网页

这是一个静态 GitHub Pages 页面，用于展示亲智聊【亲子记录】与【AI亲子督导】市场需求分析报告。

## 本地预览

直接打开 `index.html`。

## GitHub Pages 发布

1. 在 GitHub 创建一个新仓库，例如 `qinzhiliao-behavior-demo`。
2. 将本目录推送到仓库的 `main` 分支。
3. 打开仓库 `Settings` -> `Pages`。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/root`。
6. 保存后等待部署完成。

最终网址通常是：

```text
https://你的GitHub用户名.github.io/qinzhiliao-behavior-demo/
```
